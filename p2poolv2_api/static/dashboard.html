Connect a miner

  • Stratum URL:
  • Username: <payout address>.<worker name>, for example
  • Password: x,p2p=<share address>, for example
  • This node does not set a pool-wide miner_address, so every miner must send p2p= in its password with a share-chain address it controls (tp2pool / p2pool / rp2pool cashaddr).
  • To generate a share address: take a bchtest: P2PKH cashaddr from your wallet and run p2poolv2_cli bch-share-address --network chipnet <bchtest:P2PKH address> and it prints the same key under the tp2pool: share prefix.
  • Minimum share difficulty is 1. Version rolling is enabled.

Network

  • Bitcoin Cash chipnet (not testnet4 - chipnet is BCH's test network)
  • Payout addresses use the bchtest: cashaddr prefix
  • Mini share chain (256x easier than the main share chain)
  • Donation is disabled on this node (donation = 0)
  • Share chain genesis:

Peering

  • P2P multiaddr: (port 6884, open by design, no invite needed)
  • To connect: peer must use chipnet + mini share chain, then set dial_peers = ["<this multiaddr>"] in its [network] config and restart. Their log shows Identified Peer ... /p2pool/test/<genesis>/1.0.0 with the same genesis as shown on the Network card; the P2P peers card on the dashboard goes to 1+.
  • NAT or inbound-only peer: give the dashboard operator your multiaddr and this node can dial out instead.

API endpoints

All routes require the Basic auth you signed in with; only the blocked-IP routes change node state.

  • GET /health - liveness probe
  • GET /metrics - Prometheus exposition (shares, difficulties, stratum, P2P, workers, storage)
  • GET /chain_info - tip height/blockhash, total work, genesis
  • GET /shares?to=&num= - confirmed shares + uncles for a height range (num ≤ 100)
  • GET /candidates?to=&num= - candidate-chain shares + uncles (pre-confirmation)
  • GET /dag?to=&num= - all share headers per height regardless of status (full DAG)
  • GET /share_headers?to=&num=&include_txs=&include_merkle_branches= - raw share headers for tooling
  • GET /share?blockhash= or ?height= - single-share lookup (validation state, chain position)
  • GET /miner?address=&limit= - PPLNS window for a payout or share address (weight, fractions, anchor)
  • GET /transaction?txid=&raw= - pool transaction (e.g. coinbase) lookup
  • GET /peers - connected libp2p peers (multiaddrs, protocol)
  • GET /pplns_shares?limit=&start_time=&end_time= - flat recent PPLNS share list
  • GET /blocked_ips - list blocked peer IPs; POST block, DELETE unblock (mutating)
  • GET /ws?token=<base64 user:pass> - live events; subscribe with {"action":"subscribe","topic":"shares"|"peers"}

Dashboard data

This page reads the node's existing API: /metrics, /chain_info, /shares and /miner. Found-block and miner stats come from the Prometheus exposition served at /metrics and are polled every 15 seconds. New shares stream in live over the WebSocket at /ws, with the 15-second share poll kept as a fallback when the socket is down. API endpoints require the Basic auth you signed in with; sign-out only clears this page's session.
